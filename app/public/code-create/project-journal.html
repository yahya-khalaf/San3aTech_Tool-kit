PART 01

BE A BUG HUNTER

Every coder makes bugs. Finding them is the skill.

SAN3A ACADEMY SESSION 04ONLINE
CONCEPT

Two Types of Bugs

⚠️

Syntax Error

Wrong writing: Misspelled commands, bad indentation, or missing colons. The editor highlights the line and stops.

🧩

Logical Error

Wrong thinking: Code runs without crashing, but does the wrong thing (e.g. pressing A shows B). You must test to catch it!

SAN3A ACADEMY SESSION 04ONLINE
ACTIVITY

Find the Bug 🐛

  1. ⏱Time: 30 MIN
  2. 🎯Spot the most bugs — you win!
  3. 1Read each buggy code block carefully
  4. 2Write down what's wrong and how to fix it
  5. 💡Read top-to-bottom, check every line

Bug #1: The One-Time Heart

from microbit import * if button_a.is_pressed(): display.show(Image.HAPPY)

🎯 Goal: Show a happy face whenever Button A is held down.

❓ What's wrong with this code? What happens when you run it?

🔍 Hint: Press Button A after uploading — does it keep checking continuously?
SAN3A ACADEMY SESSION 04ONLINE
DEBUG 1 · SOLUTION

Bug #1: The Fix

from microbit import * while True: if button_a.is_pressed(): display.show(Image.HAPPY)

Goal: Show happy face continuously

⚠️ The Bug:
Missing while True: loop! Python checks Button A once at startup and stops immediately.
✅ The Fix:
Wrap the if condition inside a while True: loop so it checks constantly!

DEBUG 2 · QUESTION

Bug #2: The Invisible Letter

from microbit import * while True: display.show(Image.HEART) display.clear()

🎯 Goal: Flash a heart continuously on the screen.

❓ What will the display actually look like when run?

🔍 Hint: It switches between show and clear in microseconds!
SAN3A ACADEMY SESSION 04ONLINE
DEBUG 2 · SOLUTION

Bug #2: The Fix

from microbit import * while True: display.show(Image.HEART) sleep(500) display.clear() sleep(500)

Goal: Flash a heart continuously

⚠️ The Bug:
No sleep() delay! The micro:bit displays and clears the heart in microseconds.
✅ The Fix:
Add sleep(500) after show() and clear() so each state stays visible!

Bug #3: The Silent Speaker

music.play(music.POWER_UP) display.show(Image.HAPPY)

🎯 Goal: Play a startup tune and show a smiley face.

❓ Will this code run? What error will the editor show?

DEBUG 3 · SOLUTION

Bug #3: The Fix

from microbit import * import music music.play(music.POWER_UP) display.show(Image.HAPPY)

Goal: Play tune and show smiley

⚠️ The Bug:
Missing import music and from microbit import * libraries at the top!
✅ The Fix:
Always import the microbit and music modules before calling their functions.

DEBUG 4 · QUESTION

Bug #4: Capital Letters

from microbit import * while True: if button_a.is_pressed() AND button_b.is_pressed(): display.show(Image.HAPPY)

🎯 Goal: Smile when both Buttons A and B are pressed together.

❓ Syntax error or logic error? What happens when you run this?

🔍 Hint: Pay close attention to Python's capitalization rules!
SAN3A ACADEMY SESSION 04ONLINE
DEBUG 4 · SOLUTION

Bug #4: The Fix

from microbit import * while True: if button_a.is_pressed() and button_b.is_pressed(): display.show(Image.HAPPY)

Goal: Smile on A + B pressed

⚠️ The Bug:
Syntax Error! Capitalized AND is invalid in Python.
✅ The Fix:
Python logic keywords are strictly lowercase — change AND to and.

DEBUG 5 · QUESTION

Bug #5: The Swap Trap

from microbit import * while True: if button_a.is_pressed(): display.show(Image.SAD) if button_b.is_pressed(): display.show(Image.HAPPY)

🎯 Goal: Pressing A shows Happy 😊, pressing B shows Sad 😢.

❓ This code runs without errors... what's wrong?

🔍 Hint: Check which image is paired with which button press!
SAN3A ACADEMY SESSION 04ONLINE
DEBUG 5 · SOLUTION

Bug #5: The Fix

from microbit import * while True: if button_a.is_pressed(): display.show(Image.HAPPY) if button_b.is_pressed(): display.show(Image.SAD)

Goal: Press A = Happy, Press B = Sad

⚠️ The Bug:
Logical Error! Button A displays SAD and Button B displays HAPPY.
✅ The Fix:
Swap the images so Button A displays Image.HAPPY and Button B displays Image.SAD.
