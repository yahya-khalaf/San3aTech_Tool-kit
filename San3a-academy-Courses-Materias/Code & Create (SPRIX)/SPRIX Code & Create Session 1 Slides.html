The 30-Minute Design Sprint

Before we solve problems with technology, we master a powerful method: Design Thinking — a way to solve messy, human problems.

Our motto: Fall in love with the problem, not your solution.

SAN3A ACADEMY Design Thinking

Reimagine the school bag

  1. 1Pair up — one Designer, one User.
  2. 2Interview (5 min) — what’s the worst thing about your bag? When did it fail you?
  3. 3Define — “My user needs a way to ___ because ___.”
  4. 4Ideate & sketch — 3–5 wild ideas, then draw the best one.
  5. 5Test — show it; user says “I like… / I wonder…”

SAN3A ACADEMY The Display
15 min

Your first code: the Display

  • 1library — teaches the brain its commands
  • 2show — puts an image on the screen
  • 3sleep — waits, in milliseconds

SAN3A ACADEMY Loops
30 min

Spot the pattern: the for loop

for i in range(3): display.show(Image.HAPPY) sleep(500) display.clear() sleep(500)

Instead of writing the same lines over and over, a loop repeats them.

Patterns are everywhere: tiger stripes, road tiles, sunrise.

SAN3A ACADEMY Loops

Forever: the while True loop

while True: display.show(Image.HEART) sleep(500) display.clear() sleep(500)
  • ↻for loop — repeats a set number of times
  • ∞while True — repeats forever
